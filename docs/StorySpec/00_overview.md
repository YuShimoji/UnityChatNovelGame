# 00 — Overview（企画ワンページ）

## タイトル（仮）
**ハルシネーション・シミュレーター** / Hallucination Simulator

## ジャンル（要約）
**検索エンジン型チャットUI**で進む短編ノベルADV。
ミステリーの形式を取りつつ、中心は**認識論的サスペンス**（"真相"の確定ではなく、"合意可能性"の試行）。

## キャッチコピー（候補）
**もっと人間らしくふるまえ**

## プレイヤー体験（ログライン）
壊れた検索UIのような端末で、多国籍の参加者と会話する。
AIの「補完」により言葉がズレ、世界の参照先が崩れる。
プレイヤーは"推理"よりも"検証"を積み、**真実らしさの層**を段階的に踏む。

> 比喩：灯台を見つける物語ではない。霧の密度を測り、足場の硬さを確かめ、歩ける距離を延ばす物語。

## 想定プレイ
- クリア: 約1〜2時間（サブスレッド回収で増）
- セッション: 通勤等の短時間でも成立（画面羞恥耐性が高いUI）

## プラットフォーム
PC / iOS / Android / Web（テキストUI親和）

## 想定ターゲット
- **主軸**：思弁SF・哲学テキストに慣れた読者。ポスト真実問題に関心がある層
- **副軸**：Orwell / Hypnospace Outlaw / A Normal Lost Phone 等の端末探索ゲームのファン
- **感触**：「ゲームをしている」より「壊れた検索エンジンを使っている」感覚
- **公共空間**：電車内でも起動できる"羞恥耐性"設計（派手な演出を避ける）

## テーマ
- 幻覚（confabulation）と現実
- 不確実な伝達（noisy channel）
- "共通の真実"の不在と、共同作業としての合意形成
- ベケット的劇作法：停止は失敗ではなく、停止こそが劇

## 主要システム要約
- **進行**：ログ読解 → 矛盾検出 → 質問（定型選択肢） → 返答評価 → 指摘
- **通貨**：ハルシコイン（指摘・断片接触等で不透明に増える。消費財ではなく到達権）
- **消費**：サブスレッド（注釈／追跡／偵察強化）解放、扉（ゲート）開放
- **分岐**：エンディングは単一（到達条件＝全コンテンツ開放）。未到達でも成立。

## 物語構造
**3部×3節（9ブロック）**。1節＝1日。FireWatch的ペーシング（日常のルーティンと時間経過の感覚）。
部ごとに "層更新" を置く：
- 第1部末：地名混在の制度的理由らしき断片
- 第2部末：過負荷・停電・断線の痕跡
- 第3部末：部分救出（小さな達成）

## コア・ギミック：断片（Fragments）
- 得体のしれない文章の書かれた紙片／表示（混合だがテキスト主軸）
- **社会的に存在しない**（検索にも公的記録にも載らない *不可索引物*）
- 収集・照合・追跡が探索のエンジンになる
