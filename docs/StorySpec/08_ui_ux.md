# 08 — UI / UX（検索・チャットUI）

## 1. UIコンセプト
- **検索エンジン＋チャットスレッドの複合UI**
- 公共空間でも起動しやすい"羞恥耐性"設計（派手な演出を避ける）
- 「ゲームをしている」より「壊れた検索エンジンを使っている」感覚

## 2. 画面構成

### メイン画面：ダッシュボード型
- LINE的なタブ切り替えではなく、**ダッシュボード型**のメイン画面
- 通知・未読・新規断片・偵察結果が一覧で見える
- ここから各スレッドや機能にアクセスする

### スレッド画面：Discord的マルチスレッド
- メインスレッド（会話ログ）は一本の時系列
- サブスレッドは**Discord的に分岐**（メインスレッドから派生した別タブ）
- 各サブスレッド内も時系列のチャット形式

### サブスレッド構成

> **2026-03-11 更新**: サブスレッド(A/B/C)と分岐スレッドを統合型で設計。詳細は `16_subthread_ui.md` を参照。

- **A. 注釈**：用語・背景・制度・AI挙動の短い解説
- **B. 追跡（調査ログ型 / Wiki型）**：地名／機関名／出来事のリンク追跡。「参照の地獄」をWiki的に辿る
- **C. 偵察強化**：外出・探索の質を上げる（録音/撮影/採取の精度、行動指示）
- **分岐**：if分岐型の物語分岐。プレイヤーが「知識の運び屋」になる

### プレイヤーリソース表示域（インベントリ）

> **2026-03-08 策定**: 断片は汎用インベントリの一種。専用UIではなく、全プレイヤーリソースを統合管理する。

**配置**: ダッシュボード内タブ（主）+ チャット画面フローティングボタン（補助）

**ダッシュボード内**:
- 「チャンネル」タブと「インベントリ」タブの切替
- インベントリ内は3つのサブタブで分類:
  - **断片**: 紙片・文書（不可索引物）。テキストカード表示（冒頭数行+入手チャプター）
  - **記録**: 録音/撮影/採取の成果物。メディアカード表示（種類アイコン+説明）
  - **トピック**: 解放済み知識ラベル。シンプルリスト（タイトル+解放条件）
- HalluciCoin: タブではなく右上に常時数値表示

**フローティングUI**（チャット画面）:
- チャット画面のヘッダー右上にアイコンボタン
- タップでインベントリオーバーレイ（ダッシュボードのインベントリタブと同じ内容）を表示
- 会話中にアイテムを即参照可能

**デザイン言語**:
- チャンネルカードと同じカードベースのデザイン
- 各アイテムは入手順に並ぶ（カテゴリ内ソート）
- 「壊れた検索エンジン」の世界観に合わせた控えめなUI

### フッター
- 定型選択肢（主人公バルナビーの制約を反映）
- 指摘アクション（ハルシネーションのタグ付け）

## 3. 通知システム：リアルタイム割り込み型
- ダッシュボードに通知が**リアルタイムで割り込む**
- 新しい断片の発見、AI応答、偵察結果、ハルシコイン変動
- 通知の頻度・音像は設定で調整可能（公共空間対応）
- 重要度に応じた優先度表示（全てが同じ重みではない）

## 4. 操作の手触り
- 選択肢は幼弱に見えるが、含意（implicature）で介入可能
- **"指摘"はログにタグ付けする動作**として表現し、コイン獲得へ接続
- テキスト長押し→指摘メニュー、のような直感的操作

## 5. 演出ポリシー
- 通知音：頻度で音像を変えられる（多いほど小気味よく）
- 断片表示：過剰なホラー演出は避け、淡い異物感を維持
- UI遷移：滑らかだが控えめ。派手なアニメーションは避ける
- エラー表示：システム障害の演出とUIエラーの区別を慎重に設計（プレイヤーが混乱しないよう）

## 6. チャットバブル仕様（2026-03-07 策定）

### 6.1 バブル外観
- **背景**: 9スライス Rounded Sprite（角丸）。CharacterProfile の ThemeColor で着色
- **角丸半径**: ChatUIConfig パラメータで調整可能
- **バブル幅上限**: 画面幅の `bubbleMaxWidthPercent`（デフォルト 70%）と `bubbleMaxWidthPx` の**小さい方**を採用
- **サイドマージン**: `sideMarginPercent` + `sideMarginMaxPx` の二重制約で狭画面での崩れを防止
- バブル幅は ChatUIConfig で調整可能。Android 画面サイズを今後標準とする
- テキストは `enableWordWrapping = true` で折り返し
- テキストパディング: 上下左右均等（ChatUIConfig で指定）

### 6.2 キャラクター表示
- **表示モード**: アイコンのみ / アイコン+名前 / 名前のみ を CharacterProfile で切替可能
- チャプター進行に応じて表示モードを変更可能（例: 初期は名前のみ → 信頼度上昇でアイコン表示）
- アイコンはバブル横（NPC: 左、Player: 右）に小さく表示
- Player バブルにはアイコン・名前を表示しない

### 6.3 タイピングインジケーター
- バブルとは**別の専用 UI** として実装
- 入力行上部またはスクロール末尾に固定表示
- 「...」のドットアニメーション（DOTween で制御）
- `<<StartWait>>` 開始時に表示、メッセージ到着時にフェードアウト
- チャット履歴には残らない（一時表示のみ）

### 6.4 選択肢表示
- **メッセージ埋没型**: 選択肢はメッセージバブルと同じ流れに溶け込む控えめなデザイン
- 色は暗めグレー青（NPC バブルに近い色調）、テキスト左揃え
- 高さ・フォントサイズともに通常バブルに近い小型設計
- 選択肢は ScrollRect 内に配置（ポップアップではない）
- 選択後、選択されたテキストがプレイヤーメッセージとして確定表示
- 未選択の選択肢は CanvasGroup DOFade でフェードアウト
- パラメータは全て ChatUIConfig SO で調整可能

### 6.5 入力欄
- **将来非表示予定**。プロトタイプ段階のモック
- プレイヤーの発言は全て選択肢から行う（自由入力なし）
- 非表示時は画面下部にスクロール余白のみ残す

### 6.6 矛盾指摘タップ演出
- **長押し（1つ目選択）**: バブルに光る枠線 + 軽いスケールパルス
- **タップ（2つ目選択）**: 軽いスケールパルス + 色変化（判定中）
- **成功**: 緑フラッシュ + 接続線 + 通知（既存 Phase 2 実装を維持）
- **失敗**: 赤フラッシュ + シェイク（既存 Phase 2 実装を維持）

### 6.7 デバッグ機能
- **Debug Hub（F12）**: 全 Yarn ノード一覧、チャプター別グループ化、**ストーリー順ソート**（Yarn ファイル内 title: 行出現順）
- **早送り（F11）**: タイピングインジケーター遅延とタイプライター待ちをスキップ。デバッグオーバーレイに `[FF]` 表示
- **デバッグオーバーレイ**: 折りたたみ式。現在のノード名・行ID・タグを表示。タップで展開/折りたたみ
