# 11 — Production Plan

**最終更新**: 2026-03-03
**体制**: ソロ開発（AIアシスタント活用）

## 開発体制（2026-03-03確定）

**1人で全工程を担当**。AIアシスタント（Claude Code等）を活用して補完。

| 役割             | 担当           | AI活用                                   |
| ---------------- | -------------- | ---------------------------------------- |
| シナリオライター | 本人           | たたき台生成、校正、ローカライズ補助     |
| プログラマー     | 本人           | コード生成、デバッグ、アーキテクチャ設計 |
| UI/GUIデザイン   | 本人           | レイアウト案、プロトタイプ               |
| イラスト         | 本人（最小限） | 抽象/シルエット系で対応可能              |
| BGM/SE           | 本人           | フリー素材 or 生成AI音楽の活用           |

## オーディオ方針（2026-03-03確定）

- **BGM**: PsyAmbient系（低周波の疑念、環境音楽的）
- **SE**: 操作SE、コメントポップ、指摘音（パンチ+コイン）、偵察ログ環境音、システム通知
- **ボイス**: なし（フルボイスなし、AI音声読み上げもなし）

## 対応言語（2026-03-03確定）

- **日本語**（主言語）+ **英語**
- Yarn Spinnerのローカライズ機能を活用予定
- Unity Localization パッケージの導入を検討

## フェーズ案

1. 企画固定（本パックの未確定を埋める）← **ほぼ完了**（2026-03-03）
2. 章立て確定（9ブロック→各節のシーン列）← **進行中**
3. 断片ライブラリ制作（チャプターテーマに合わせて流動的に設計）
4. 実装（UI→ログ→サブスレッド→セーブ）
5. テスト（読解導線／不快域／停滞の手触り）
6. リリース準備（ストア文言、トレーラーは最小）

## 成果物の定義（MVP）

- 9ブロックを完走できる
- 断片：各節最低1つ（合計9+α）
- サブスレッド：各種最低3つ（合計9+α）
- メインストーリー: 1-2時間で完走可能
- 日本語+英語の両対応
