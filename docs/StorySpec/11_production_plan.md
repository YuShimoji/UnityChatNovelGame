# 11 — Production Plan（体制・スケジュール叩き台）

## 必要役割
- シナリオライター（本線＋断片本文）
- デザイナー（UI/GUI）
- イラストレーター（ポートレート、断片の挿絵、静的画像）
- プログラマー（UI、ログ、サブスレッド、セーブ等）
- サウンド（BGM/SE）

## フェーズ案
1) 企画固定（本パックの未確定を埋める）  
2) 章立て確定（9ブロック→各節のシーン列）  
3) 断片ライブラリ制作（文体カテゴリ×節）  
4) 実装（UI→ログ→サブスレッド→セーブ）  
5) テスト（読解導線／不快域／停滞の手触り）  
6) リリース準備（ストア文言、トレーラーは最小）

## 成果物の定義（MVP）
- 9ブロックを完走できる
- 断片：各節最低1つ（合計9+α）
- サブスレッド：各種最低3つ（合計9+α）
