# 07 — Fragments（断片：不可索引物）

## 1. 定義
得体のしれない文章の書かれた「断片」。
**社会的に存在しない**：検索に出ず、公的記録に載らず、しかし手元には残る（**不可索引物** / unindexable artifact）。

## 2. 役割
- 探索の主エンジン：収集・照合・追跡で物語が進む
- **"説明"より"欠損した参照そのもの"に価値がある**（脚注が無い、条文参照が消えている等）
- 中盤（4節）で中心ギミックとして確立：「検索しても出ない」ことの意味が問われる
- 終盤（9節）では"鍵"として扉/ゲートを開ける（最後の断片が道を開く）

## 3. 証拠フォーマット（D混合／C軸）
- **主軸**：テキスト断片（紙片・掲示・レシート・文書等）
- **補助**：静的画像（標識、掲示物の写真）、環境音（録音）
- 露悪・グロは排除。静的で薄い不穏
- 偵察強化（サブスレッドC）で採取精度が向上する

## 4. 断片の設計パターン（例）

| パターン | 説明 | 登場節 |
|----------|------|--------|
| 参照欠損の条文 | 条文番号があるが、参照先が存在しない | 1-2節 |
| 二重地名 | 地名が二重表記（体系が跨る） | 2-3節 |
| 空白の発行主体 | 更新通知風だが、発行主体が空白 | 3-5節 |
| 教材の残骸 | テスト問題風だが、正解欄が欠損（普遍教育の影） | 4節 |
| 停電手順書 | 負荷警報風の文書、だが誰が書いたか不明 | 6節 |
| 倫理警告文 | 規格化の影を感じさせる形式的な警告 | 8節 |
| 最終鍵 | 説明ではなく扉を開ける機能として作用 | 9節 |

## 5. 断片の物語的機能

### 節ごとの役割変遷
- **1-3節（導入）**：「何かおかしい」の手がかり。短く、参照欠損が目立つ
- **4-6節（確立）**：不可索引物としての確信。収集・照合が本格化
- **7-9節（収束）**：鍵としての機能。断片が行動を可能にする

### ベルナルドとの関係
- ベルナルドの文体分析スキルが断片読解の核になる
- 文体カテゴリの差異（行政文書 vs 教育教材 vs 個人メモ）をベルナルドが見抜く
