# 09 — Audio / Visual Direction

## 1. ビジュアル
- **キャラクター**：最小限（立ち絵は抽象・シルエット寄りも可）。チャットUIがメインのため、ビジュアルの主張は抑える
- **背景**：写真加工／静的な不穏（廃墟、理由不明の物体）。美しくも空虚な風景
- **UI**：検索/チャット風（生活に溶ける）。「ゲームをしている」より「壊れた検索エンジンを使っている」感覚
- **断片表示**：過剰なホラー演出は避け、淡い異物感を維持。テキスト主軸

## 2. サウンド
- **BGM**：PsyAmbient基調（低周波の疑念を常在。環境音楽的な空気感）
- **SE**：
  - 選択決定音
  - コメントポップ（頻度で音像が変わる＝通知が多いほど小気味よく）
  - 指摘：殴打音＋コイン散乱（正しい指摘の手応え）
  - 偵察ログ：環境音（風・砂利・フェンス・足音・ドア）
  - システム通知：控えめなチャイム（公共空間対応）

## 3. ボイスポリシー
- **基本方針**：フルボイスは想定しない（テキスト主軸の作品性を維持）
- **検討枠**：
  - 感情を載せない読み上げ（AI音声風）は世界観に合う可能性あり
  - 環境音ベースの抽象的な"声"（意味のない音声断片）は演出として検討可
- **決定事項**：偵察ログの環境音は必須（没入の主要素）

## 4. コンテンツライン（表現の限界線）

### 許容する表現
- 不穏・不安・孤独感
- 情報の欠損・参照の破綻
- 制度の形骸化・インフラの静かな死
- 停電・通信断絶の描写
- 無人の空間の美しさと空虚

### 排除する表現
- グロテスク（流血・身体損壊）
- 露悪（精神的虐待・差別的表現）
- ジャンプスケア・過剰なホラー演出
- 性的コンテンツ
- 暴力による解決・アクションシーン

### 基調
- **静的で薄い不穏**。「何かがおかしいが、それが何かは分からない」
- 恐怖ではなく不安。驚かすのではなく疑わせる

## 5. 公共空間ポリシー
- 音量は控えめにできる設計（イヤホンなしでも周囲に迷惑をかけない）
- 画面表示は「チャットアプリを使っている」ように見える
- 過激な画像・テキストが突然表示されない
- 通勤電車内でのプレイを想定した"羞恥耐性"設計
