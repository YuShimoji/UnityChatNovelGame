## 1. ストーリー構成: 3部3章3節

### 構造
```
第1部（Act 1: 導入）
├── 第1章 [セッション1, 2, 3]
├── 第2章 [セッション4, 5, 6]
└── 第3章 [セッション7, 8, 9]

第2部（Act 2: 展開）
├── 第4章 [セッション10, 11, 12]
├── 第5章 [セッション13, 14, 15]
└── 第6章 [セッション16, 17, 18]

第3部（Act 3: 結末）
├── 第7章 [セッション19, 20, 21]
├── 第8章 [セッション22, 23, 24]
└── 第9章 [セッション25, 26, 27]
```

### 用語定義
| 用語 | 定義 | ゲーム内の単位 |
|------|------|--------------|
| 部 (Act) | ストーリーの大きな区切り | 導入/展開/結末 |
| 章 (Chapter) | テーマや登場人物の変化の区切り | 3セッション分のまとまり |
| 節 (Session) | チャットの1日分 | 1回のプレイセッション |

### 現在のファイルとの対応
| ファイル名 | 構成上の位置 |
|-----------|------------|
| `Ch1_Terminal.yarn` | 第1部・第1章・セッション1（1日目） |
| `Ch2_LocationConfusion.yarn` | 第1部・第1章・セッション2（2日目） |
| （未作成） | 第1部・第1章・セッション3（3日目） |

### 命名規則の課題
現在の `Ch1`, `Ch2` は「セッション」に相当する。今後のファイル命名を検討する必要あり。
- 案: `P1C1S1_Terminal.yarn`（Part1-Chapter1-Session1）
- 案: 現行の `Ch*` をそのまま通し番号で使い続ける

### プレイ時間見積もり
- 1セッション: 10-20分
- 1章（3セッション）: 30-60分
- 全体（27セッション）: 4.5-9時間

## 2. チャプター間遷移

- **基本方針**: 自動遷移（セッション終了後に次のセッションへ自動進行）
- **演出要望**: 要所でプレイヤーにあえて選ばせることで「遊んでいる感」を演出
  - 例: 章の区切りで「続ける / 一度休む」のような選択
  - ゲーム終了前にチャプター選択画面を見せることは避ける
- **優先度**: 演出面のため現時点では非必須

## 3. グリッチ演出

### レベル定義
| レベル | 演出内容 | 使用場面 |
|--------|---------|---------|
| Lv1 | テキストのみ: 文字化け、ノイズ文字混入、一時的な文字崩れ | 軽微な通信異常 |
| Lv2 | テキスト + 画面軽微: バブルの色ずれ、軽いスキャンライン | 中程度の異常、重要な情報の接近 |
| Lv3 | 画面全体: ノイズ、色ずれ、スキャンライン、画面振動 | 重大イベント、クライマックス |

### 実装方針
- Lv1: TextMeshPro のテキスト操作（文字置換、richtext）
- Lv2: Lv1 + Image コンポーネントの色変更、簡易Shader
- Lv3: PostProcessing / FullScreen Shader

## 4. 矛盾指摘システム

### フロー概要
```
1. チャット中に矛盾を含むバブルを発見
2. バブルをタップ → フライアニメーションでボードに送る
3. ボード（DeductionBoard）で証拠を管理
4. 必要な証拠が全て揃ったら自動的にトピック解放
```

### ボード仕様
| 項目 | 仕様 |
|------|------|
| スロット数 | 3-4（少数精鋭、取捨選択が発生） |
| アクセス方法 | チャット画面上部のタブ切り替え（「チャット」「ボード」） |
| 満杯時 | 「ボードが満杯です」通知を表示。先に空ける必要あり |
| 不正解ペナルティ | なし（自由に試行錯誤可能） |
| 証拠の戻し | ボードから戻して別の証拠と入れ替え可能 |

### 証拠グループ
- **ペアではなくグループ化**: 2つ以上の証拠で1つのトピックを解放
- **成立条件**: 必要な証拠が全てボード上に揃った時点で自動解放
- **例**: トピックAの解放に証拠X, Y, Zの3つが必要
  - X, Yだけでは成立しない
  - X, Y, Zが全てボードに載った瞬間にトピックA解放

### UI演出
- **バブルタップ**: バブルがハイライト
- **ボードに送る**: フライアニメーション（バブルからタブ方向へ飛ぶ）
- **トピック解放**: 解放演出（エフェクト + システムメッセージ）

### 用途: サブシナリオ（探索シナリオ）解放

## 7. TypingIndicator演出

### ハイブリッド方式（確定済み）
- **自動表示**: NPCメッセージ前に0.3秒のTypingIndicator自動表示（ChatDialogueView）
- **手動制御**: `<<Typing true>>` + `<<StartWait N>>` + `<<Typing false>>` で長め演出
- **スキップ条件**: プレイヤーメッセージ、早送りモード有効時

### 演出パターン（実装済み）
| 場面 | 待機時間 | 意図 |
|------|---------|------|
| 初回接続（Ch1） | 1.5s | 世界への最初の接触 |
| セッション開始（Ch2+） | 1.0s | 日常的な接続 |
| 新キャラ初登場 | 1.0-1.5s | 新しい存在の登場感 |
| グリッチ後の復帰 | 2.0s | 緊張感、不安定さ |
