# Evidence Reuse

証跡再利用の現行ルールを1ページに集約する。

## 再利用可の条件

以下を全て満たす場合のみ再利用可:

1. 証跡ファイルが存在し、欠損がない
2. テスト名・対象範囲が今回と一致
3. 証跡取得後に対象コード/依存/シーン変更がない
4. 実行日時が古すぎない（既定: 30日以内）
5. 結果が合格基準を満たす（既知FAILは根拠付きで許容）

## 再利用不可の条件

- 対象コード変更あり
- 実行環境変更あり（Unity版・OS・ビルド設定）
- ログ/結果/スクリーンショットの欠損
- 期限超過

## 最小ワークフロー

1. 証跡存在確認
2. 差分確認（`git log --since` など）
3. 合否・既知FAILの根拠確認
4. 再利用記録を残す

## 補足

- 古い詳細版は整理済み（archive から削除）。
- 実務では `docs/verification/` と `docs/DECISION_LOG.md` を併読する。
