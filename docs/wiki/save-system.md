# セーブシステム

## 保存される情報

- 最後に訪れた Yarn ノード名
- 全 Yarn 変数 ($has_topic_*, $speaker 等)
- 解放済みトピック一覧
- チャット履歴 (Normal/System/Image 全種別)
- セーブ日時
- 完了済みチャンネルID

## オートセーブ

- 専用スロット (slot 99)
- トリガー: ノード遷移時 / 選択肢表示前 / EndDay 時
- クールダウン: 30秒 (EndDay は強制保存)
- UI: 右上に「Auto Saved」インジケーター (1秒表示)

## 保存されない情報

- スクロール位置
- 個別メッセージの既読状態
- 分岐スレッドの状態 (IsActive, TransferFlags)

## 注意点

- セーブ復元時は **ノードの先頭から再開** (行単位の復元は不可)
- チャット履歴は復元時にバブルとして即時再生成 (アニメーションなし)
- ノードを細かく分割すれば、より精密な復元ポイントを作れる
- 分岐中にセーブ → ロードすると分岐状態は失われるが、Yarn変数 ($did_branch_xxx) は保持されるため再入防止は機能する
